Audience Alignment

Persona Andy Menjadi Dasar Keputusan UI

Andy adalah mahasiswa berusia 29 tahun yang tinggal di kos Surabaya Timur, memiliki literasi teknologi cukup baik, aktif online sekitar 2-3 jam per hari, dan mengutamakan user-friendly, vibes, kualitas, serta color.

User story utama: Sebagai Andy, saya ingin menemukan gear berkualitas, melakukan pembelian, dan memantau pesanan dengan langkah sesingkat mungkin agar tidak membuang waktu pada proses yang rumit.

  1. Fast PathCatalog, Track Order, Help, dan Customer Panel tersedia langsung.
  2. User FriendlyAksi utama konsisten dan status sistem diberi feedback jelas.
  3. VibesDark premium gaming dengan hierarchy dan whitespace terukur.
  4. KualitasGaransi, rating, stok, pembayaran aman, dan tracking ditampilkan.
  5. ColorCyan digunakan sebagai action color dan status penting.

User Story Coverage

Flow Storefront dan Admin Dipisahkan

Customer dapat menemukan produk, membaca informasi kualitas, membeli, membayar, melacak, dan melihat transaksi. Admin mengelola produk, artikel, pengguna, transaksi, dan dashboard melalui area terpisah.

  1. BrowseLanding → Catalog
  2. EvaluateProduct Detail → Review
  3. PurchaseCart → Checkout → Payment
  4. After-salesSuccess → Track → History
  5. CustomerLogin → Customer Panel
  6. AdminDashboard → Manage Data
